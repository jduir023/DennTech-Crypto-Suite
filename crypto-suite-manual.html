Getting Started

Double-click DennTechCryptoSuite.exe to launch. A splash screen appears briefly while the app initializes, then the main window opens on the Portfolio Tracker tab. The app requires no installation — all settings and portfolio data are saved automatically in the data/ folder next to the executable.

First launch: The app copies default config and portfolio files into data/ automatically. You can edit data/config.json to customize risk presets and bot bridge settings at any time.
1

Portfolio Tracker

Track holdings, P&L, and allocation in real time

Add crypto holdings by clicking Add Holding and entering the coin, quantity, and average buy price. Live prices are fetched from CoinGecko and the tracker instantly calculates unrealized P&L in both USD and percentage for each position as well as your overall portfolio.

Key Features

  • Add / Edit / Remove holdings from the sortable table
  • Import CSV for bulk entry of existing positions
  • Allocation view — percentage breakdown of each coin by value
  • Save Snapshot — records the portfolio state to history so you can track growth over time
  • Total portfolio value and aggregate P&L displayed at the top
Portfolio data is stored in data/portfolio.json and persists between sessions.

DCA Planner

Simulate dollar-cost averaging against real historical data

The DCA Planner lets you replay any DCA strategy against real historical price data to see exactly how it would have performed — and compare it against investing everything at once.

How to Use

  1. Select a coin from the dropdown
  2. Enter a USD amount per period (e.g. $100)
  3. Choose a frequency: weekly, biweekly, or monthly
  4. Set a date range (up to 365 days of history)
  5. Click Run Simulation

Results

  • Full purchase log — date, price paid, units bought, cumulative invested and units held
  • Final value vs. total invested and total return %
  • DCA vs. lump-sum comparison — see whether spreading buys beat a single entry at the start
  • Average, best, and worst purchase prices
  • Interactive chart overlaying DCA portfolio value, lump-sum value, and coin price over time

Tax Estimator

FIFO, LIFO, and HIFO capital gains calculation with CSV export

Import your exchange transaction history and calculate realized capital gains or losses using the accounting method of your choice.

Supported Exchange CSV Formats

  • Coinbase — standard export format
  • Binance.US — Date(UTC) format
  • Kraken — ledger export
  • Generic — date, type, coin, amount, price_usd, fee_usd

Accounting Methods

  • FIFO (First In, First Out) — oldest lots sold first; common default in most jurisdictions
  • LIFO (Last In, First Out) — newest lots sold first
  • HIFO (Highest In, First Out) — highest-cost lots sold first; minimizes realized gains

Output

  • Transaction table with matched lots and gain/loss per sale
  • Per-coin realized gains summary
  • Short-term vs. long-term capital gains breakdown (held < 1 year vs. ≥ 1 year)
  • Estimated tax liability at a configurable tax rate
  • Export CSV — saves the full gains report for your accountant or tax software

Coin Comparison

Side-by-side benchmarking across multiple assets

Compare multiple cryptocurrencies side-by-side over a shared time window. The comparison table displays 24h change %, 7d change %, market cap, volume, and 90-day performance statistics so you can quickly benchmark assets against each other without switching between tools or browser tabs.

Select coins from the dropdown list and click Compare. Data is fetched live from CoinGecko and displayed in a sortable table.

Bot Monitor

Live status panel for the DennTech Trading Bot

If you run the DennTech Trading Bot on your local machine, the Bot Monitor tab connects to its HTTP API and displays live operational status in real time.

What it Shows

  • Bot health status (running / stopped / error)
  • Active strategy and current open position details
  • Unrealized P&L on any open trade
  • Account balance as reported by the bot
  • Bot uptime and recent trade log

Configuration

Open data/config.json and edit the bot_bridge section:

base_url — default http://127.0.0.1:8765
api_key — leave empty if the bot runs without authentication
poll_ms — refresh interval in milliseconds (default 2000)

The connection is entirely local — no cloud relay, no external server. The bot must be running on the same machine for this tab to show data.

Data & Privacy

Everything stays on your machine. No telemetry is collected. No account is required. Price data is fetched from the CoinGecko public API and cached locally in data/cache/ to reduce repeated requests.
